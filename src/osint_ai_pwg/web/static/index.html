Password guessing demo

how much can an AI guess your password from what's public about you? DEMO · made-up people only

What is this?

A research tool. It checks whether an AI can guess a person's password just from details that are public about them online (their name, birthday, email, city…).

1Pick a person All test people are made up — no real individuals are ever used.
2Find their public info The tool simulates what an online search would turn up about them.
3Let the AI guess That info is handed to a password-guessing AI. Did it guess right?

Step 1 · Choose a person to test

Each option is a synthetic (fake) person. The label after it says how much is "public" about them: rich = lots, moderate = some, sparse = very little.

Add yourself (or a consenting person)

For you or someone who agreed only. Use a throwaway password you made up for this — never a real one. It's saved to a local file on this machine. In demo mode the online search is simulated, not real.
Glossary — the technical terms behind the plain words
OSINT
Open-Source Intelligence — public info anyone can find online. Shown here as "public info we found".
PII
Personally Identifiable Information — the personal details (name, email, birthday…) fed to the guesser.
Footprint (rich / moderate / sparse)
How much is publicly available about a person.
Confidence
How sure the tool is that a recovered detail is correct, after combining sources.
Crack / guess number
"Cracked" = the AI's guess list contained the real password. The guess number is which try it was.
Conditions
The named runs of the experiment. Each gives the AI a different slice of info to isolate what matters.
Ablation (the "minus" rows)
Removing one group of details on purpose to see if it was load-bearing.
